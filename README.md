# 🎓 Online Course Management System

A complete web-based Online Course Management System built using ASP.NET Core MVC.

## 🚀 Project Overview

This system provides an organized platform for managing online courses,
students, instructors, categories, and course-related data.

## 🛠️ Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap
- JavaScript

## ✨ Features

- Course Management
- Category Management
- Student Management
- Instructor Management
- Authentication & Authorization
- Image Upload
- Search & Filtering
- Data Validation
- Entity Framework Core
- SQL Server Database
